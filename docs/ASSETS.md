# Recursos visuais e créditos

Os créditos consolidados e os direitos de terceiros estão em [ATTRIBUTIONS.md](../ATTRIBUTIONS.md).

As imagens originais da interface foram mantidas por decisão explícita do mantenedor. Isso preserva a identidade visual; **não constitui comprovação de direitos de redistribuição**. O [inventário por arquivo e categoria](asset-inventory.json) registra a origem conhecida e as pendências, sem atribuir licenças presumidas.

| Categoria | Origem | Classificação e condições |
| --- | --- | --- |
| Banner SVG da documentação | Composição textual/geométrica criada para o VOID | Próprio; licença ainda a definir pelo autor. |
| Banners, logos, imagens de personagens e tela de acesso | Arquivos fornecidos ao projeto, frequentemente relacionados a franquias | Direitos não confirmados. Nenhum comprovante de redistribuição foi apresentado. |
| Avatares | Catálogo de personagens em JSON; imagens publicadas separadamente no Storage | Direitos não confirmados. Não foram exportadas fotos pessoais nem dados de usuários do Storage. |
| Pôsteres de filmes/séries | TMDB | Fornecidos por API externa e dependentes dos termos/atribuição. Não são licenciados pela licença do VOID. |
| Capas e imagens de jogos | IGDB, Steam e RAWG quando selecionado o modo legado | Fornecidos por APIs externas, sujeitos aos respectivos termos e direitos. |
| Imagens de anime | MyAnimeList/Jikan-Edge, AniList, TMDB e Fanart.tv | Fornecidos por APIs externas; verificar termos e direitos dos titulares. |
| Poppins e Press Start 2P | Fontsource | Licenciadas para redistribuição sob SIL OFL 1.1, preservando copyright, licença e Reserved Font Names. Avisos em [licenses/](licenses/). |
| Ícones SVG inline | Implementação local no código, sem pacote de ícones externo identificado | Origem detalhada dos paths não documentada; não declarar autoria exclusiva sem revisão. |
| Screenshots | Capturas reais sem conta identificável | Composição da interface com artes/marcas de terceiros; mesmas pendências das imagens representadas. |

Alternativas caso o responsável precise de uma distribuição com direitos comprovados: obter autorização específica; substituir artes por composições próprias; usar assets com licença compatível preservando atribuição; ou carregar imagens apenas por integrações autorizadas conforme termos do provedor. Nenhuma dessas substituições foi imposta à interface nesta versão.

## Provedores e atribuições

- [TMDB](https://www.themoviedb.org/api-terms-of-use): este produto utiliza a API do TMDB, mas não é endossado nem certificado pelo TMDB.
- [IGDB/Twitch](https://api-docs.igdb.com/#terms-of-service), [Steam Web API](https://steamcommunity.com/dev/apiterms) e [RAWG](https://rawg.io/apidocs): consulte os termos de dados, imagens e uso de API.
- [Jikan](https://github.com/jikan-me), MyAnimeList, [AniList](https://docs.anilist.co/guide/terms-of-use) e [Fanart.tv](https://fanart.tv/): serviços e titulares distintos. Uma integração técnica não transfere direitos de imagem. Consulte também a restrição de serviços concorrentes da AniList em [ATTRIBUTIONS.md](../ATTRIBUTIONS.md).
- A pesquisa de Steam Families considerou o projeto [salah153/steam-family-library](https://github.com/salah153/steam-family-library), identificado como MIT. O código experimental baixado e seus relatórios privados não integram este repositório; preserve a licença se redistribuí-lo futuramente.

As dependências de software mantêm suas próprias licenças nos pacotes. Nenhuma licença MIT ou outra licença foi aplicada ao código do VOID nesta preparação.
